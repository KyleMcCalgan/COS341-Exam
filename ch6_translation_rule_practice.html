Six worked variations on 2024 Question C · Chapter 6 intermediate-code translation

These are practice questions, not known exam questions. Each answer states the behaviour it assumes: an exam question's grammar, provided functions and semantics take priority.

MethodDo–whileUnlessElse-ifBounded forSwitchBreak / continue

Common setup and method

Write translation functions that return code. They do not run the source program while translating it.

  • transStat(S, table) translates a statement; transExp(E, table, place) computes an expression into place.
  • transCond(C, Lt, Lf, table) returns code that jumps to Lt when C is true or Lf when false.
  • newlabel() and newvar() produce fresh labels and temporary variables. ++ concatenates sequences of intermediate instructions.
  • [LABEL L], [GOTO L] and [IF x = y THEN Lt ELSE Lf] are instruction sequences. Adapt notation and argument order to the functions given in your exam.

First trace what runs and where control goes; give destinations labels; then assemble the returned code in execution order. Even if translator functions are called while constructing the answer, their returned code runs only when the generated program runs.

1 · Do–while

Practice question: Translate do ALGO while COND. The body runs once before the first test; repeat while COND is true.

Answer

transDoWhile(ALGO, COND, table):
    start = newlabel()
    exit  = newlabel()
    body  = transStat(ALGO, table)
    test  = transCond(COND, start, exit, table)

    return [LABEL start] ++ body ++ test ++ [LABEL exit]

Trace: Execute the body, then the test. True returns to start; false reaches exit. The body always runs at least once.

Compare repeat ALGO until COND: there, true exits and false loops, so the condition's two destinations are reversed.

2 · Unless

Practice question: Translate unless COND then ALGO: execute ALGO only when COND is false.

Answer

transUnless(COND, ALGO, table):
    bodyLabel = newlabel()
    end       = newlabel()
    test      = transCond(COND, end, bodyLabel, table)
    body      = transStat(ALGO, table)

    return test ++ [LABEL bodyLabel] ++ body ++ [LABEL end]

Trace: True goes directly to end; false goes to bodyLabel, executes the body and falls through to the end.

3 · If / else-if / else

Practice question: Translate if C1 then A1 else if C2 then A2 else A3. Test C2 only if C1 is false; execute exactly one branch.

Answer

transElseIf(C1, A1, C2, A2, A3, table):
    first  = newlabel()
    test2  = newlabel()
    second = newlabel()
    third  = newlabel()
    end    = newlabel()
    codeC1 = transCond(C1, first, test2, table)
    codeA1 = transStat(A1, table)
    codeC2 = transCond(C2, second, third, table)
    codeA2 = transStat(A2, table)
    codeA3 = transStat(A3, table)

    return codeC1 ++ [LABEL first] ++ codeA1 ++ [GOTO end]
         ++ [LABEL test2] ++ codeC2
         ++ [LABEL second] ++ codeA2 ++ [GOTO end]
         ++ [LABEL third] ++ codeA3 ++ [LABEL end]

The two GOTO end instructions prevent a completed branch from falling into a later branch. A3 already falls directly into the end label.

4 · Bounded for-loop

Practice question: Translate for i := start to end do ALGO, counting up by one with an inclusive upper bound.

Assumptions: evaluate start, then end, once before the loop; the body does not modify i. The variable table maps i to its intermediate variable. The IR supports <= and +.

Answer

transBoundedFor(i, startExp, endExp, ALGO, table):
    startValue = newvar()
    bound      = newvar()
    loop       = newlabel()
    bodyLabel  = newlabel()
    exit       = newlabel()
    ivar       = lookup(table, i)
    first      = transExp(startExp, table, startValue)
    last       = transExp(endExp, table, bound)
    body       = transStat(ALGO, table)

    return first ++ [ivar := startValue] ++ last
         ++ [LABEL loop]
         ++ [IF ivar <= bound THEN bodyLabel ELSE exit]
         ++ [LABEL bodyLabel] ++ body
         ++ [ivar := ivar + 1, GOTO loop, LABEL exit]

Trace: With start 2 and end 4, the body sees 2, 3 and 4. If start is greater than end, the first test exits without executing the body.

If the language evaluates the bound on every iteration, move its expression code to just after LABEL loop. If it evaluates both expressions before assigning i, place last before ivar := startValue. Follow the stated semantics.

5 · Switch with two cases

Practice question: Translate switch E { case K1: A1; case K2: A2; default: A3 }.

Assumptions: E is evaluated once; K1 and K2 are distinct constants; equality is supported; exactly one body runs and cases do not fall through. A missing default would simply go to the end.

Answer

transSwitch(E, K1, A1, K2, A2, A3, table):
    value   = newvar()
    case1   = newlabel()
    test2   = newlabel()
    case2   = newlabel()
    default = newlabel()
    end     = newlabel()
    expr    = transExp(E, table, value)
    body1   = transStat(A1, table)
    body2   = transStat(A2, table)
    body3   = transStat(A3, table)

    return expr
         ++ [IF value = K1 THEN case1 ELSE test2]
         ++ [LABEL test2, IF value = K2 THEN case2 ELSE default]
         ++ [LABEL case1] ++ body1 ++ [GOTO end]
         ++ [LABEL case2] ++ body2 ++ [GOTO end]
         ++ [LABEL default] ++ body3 ++ [LABEL end]

Each test uses the same saved value of E. A matching case jumps past the other tests. The jumps after A1 and A2 prevent fall-through; remove or change them only if the source language specifies fall-through.

For more cases, repeat the test-and-label pattern. If the IR cannot compare directly with a constant, first place each constant into a fresh temporary using the provided expression translator.

6 · Break and continue inside a loop

Practice question: Extend translation of while COND do ALGO so the body may contain break and continue. A break exits the nearest loop; a continue starts its next condition test.

Pass the appropriate labels into the body translator. Ordinary statement rules forward this context to their nested statements.

Answer

transWhile(COND, ALGO, table):
    testLabel = newlabel()
    bodyLabel = newlabel()
    exitLabel = newlabel()
    test = transCond(COND, bodyLabel, exitLabel, table)
    body = transStat(ALGO, table,
                     breakTarget = exitLabel,
                     continueTarget = testLabel)

    return [LABEL testLabel] ++ test
         ++ [LABEL bodyLabel] ++ body
         ++ [GOTO testLabel, LABEL exitLabel]

transBreak(breakTarget):
    return [GOTO breakTarget]

transContinue(continueTarget):
    return [GOTO continueTarget]

A nested loop creates its own targets for its body; when its translation ends, the surrounding body still uses the outer targets. A break or continue outside a valid loop needs to be rejected by the language's checking rules.

The continue target depends on the loop: in a for-loop it normally points to the increment, then the condition; in a do–while it points to the condition after the body. Jumping straight to the body start would skip those steps.

For the bounded for-loop above, insert LABEL increment immediately before ivar := ivar + 1, translate the body with continueTarget = increment, and use its exit label as breakTarget.

Exam checklist

  1. State any behaviour the question leaves ambiguous: test timing, bounds, fall-through or nested-loop scope.
  2. Allocate fresh labels and temporaries; use the provided translators and symbol table.
  3. Put generated code in execution order. Make every condition's true and false destination explicit.
  4. Check fall-through, loop exit, zero iterations versus one iteration, and any continue target.
  5. Trace a small example through each path and compare it with the source construct.
