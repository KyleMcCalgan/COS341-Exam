One instruction per line. Forms: x := y, x := 5, x := y + z (any binop), x := -y, x := M[y], M[x] := y, LABEL l, GOTO l, IF x < y THEN l1 ELSE l2 (ELSE optional: falls through), x := CALL f(a, b), RETURN x. Constants are numbers or #name. Line numbers and // comments are ignored.
