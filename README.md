# COS341 Exam

Interactive revision walkthroughs for COS341 compiler construction. Open `index.html` to choose a guide.

## Walkthroughs

- `ch6_9_walkthrough.html` — Chapters 6 and 9, including the Semester Test 2 source pages.
- `ch8_walkthrough.html` — Chapter 8 liveness, interference, colouring, and spilling.
- `h6_walkthrough.html` — Homework 6 register allocation.
- `ch9_guide.html` — Chapter 9 call sequences and inlining.

The pages are static HTML and can be opened locally in a browser. `SOURCES/` contains the photographed test pages shown in the Chapter 6 and 9 guide.
